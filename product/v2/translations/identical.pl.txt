# Polish values that deliberately stay identical to English.
#
# `npm run check:translations` reads this file. In every catalog family named on
# the @complete line, a Polish value that equals its English source fails the
# check unless its key is listed below, so an untranslated leftover such as
# `arm_night=Arm Night` cannot come back unnoticed. A listed key whose value is
# no longer identical also fails, which keeps this list honest.
#
# Families:  firmware = strings.pl.txt (panel text)   web = web.pl.txt (configurator)
# Entries:   firmware:<key> or web:<key>, one per line; `# reason` may follow.
#
# Both Polish catalogs are complete. Only the reviewed shared words,
# product/protocol names and technical terms below may remain identical.
